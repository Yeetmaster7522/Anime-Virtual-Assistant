# Anime-Virtual-Assistant
Attempt to make Jarvis as an anime waifu/husbando (whichever fits the theme best)

<u>If you want to contribute please do so by creating a branch off of main and making your changes there</u>


## Intended features

- [ ] Capture voice commands and text input
- [ ] Respond to user (in character)
- [ ] Make a 3d model move alongside it
- [ ] Do tasks on the computer such as coding or playing games alongside user
